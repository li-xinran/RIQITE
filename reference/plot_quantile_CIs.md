# Plot quantile CIs

Given the results of a quantile CI call, plot the results.

## Usage

``` r
plot_quantile_CIs(result, k_start = NULL, main = NULL)
```

## Arguments

- result:

  Result of a

- k_start:

  Quantile to start with (if NULL, plot all informative CIs).

- main:

  Title of plot

## Value

The result object, again (invisibly).
