# Benin Data

These are the small Benin dataset, taken from Table III.H of Watchekon
(2002).

## Usage

``` r
benin
```

## Format

A data frame with 24 rows and 7 variables:

- Village:

  Village ID

- District:

  District of village

- Candidate:

  Candidate in village

- reg_voters:

  Number of registered voters

- VoteShare:

- vote_male:

- vote_male96:

- vote_female:

- vote_female96:

- Treatment:

  Is Control, Clientelist, or Policy

- Note:

  Notes on our entering data from original paper.
